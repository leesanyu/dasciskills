# Feature：字段选择与绘图轴指定

- 标识：`plot-axis-selection`
- 状态：已完成；T1→T2→T3 已依次验收并归档。
- 适用对象：选择 CSV / Excel 两字段并阅读关系图的用户。
- 关联契约：[工作表与字段选择](feat-table-selection-experience.md)、[统一报告](feat-unified-analysis-report.md)；保留现有字段物理编号、语义与方法计划。

## Non-Goals

- 不引入自变量/因变量或因果、预测模型语义，不改变统计算法、共同样本、方法选择、校正与效应量方向。
- 不通过交换 col1/col2 改变绘图方向，不修改字段业务类型或有序水平，不把有序等级默认为等距数值。
- 不建设图表编辑器，不增加坐标范围、对数轴、配色、自由选图等配置；不为轴选择新增强制问答步骤。
- 不保留旧绘图契约兼容层，不同步外部安装副本，不提交或推送。

## 业务意图与现状

用户在选完两字段时就知道图会如何摆放，并能用“X 轴用温度”“交换横纵轴”等自然语言调整。摘要、图片和报告中的轴说明必须对应；文字使用“横轴（X 轴）/纵轴（Y 轴）”，不推断变量之间的因果角色。

实施前，散点图通常 col1→X、col2→Y；分组箱线图采用横向布局，数值→X、分组→Y；时间与类别图时间→X；热图 col1 为行（Y）、col2 为列（X）。有序字段还会使主图转为箱线图或热图。原选择摘要只列两字段和方法计划，不能据此确认实际坐标方向。

## 选择与默认规则

采用“自动默认 + 摘要明示 + 可交换”。先确定字段有效类型和主图，再决定默认轴，明确指定始终优先于默认规则。

| 主图与数据 | 默认横轴 | 默认纵轴 |
|---|---|---|
| 散点图，仅一个日期时间字段 | 日期时间字段 | 另一字段 |
| 其他散点图，包括两个日期时间字段 | 第一字段 | 第二字段 |
| 分组箱线图，包括有序等级与数值 | 数值字段 | 分组/有序等级字段 |
| 时间与类别图，包括时间与有序等级 | 日期时间字段 | 类别/有序等级字段 |
| 类别或等级频数热图 | 第一字段 | 第二字段 |

“第一/第二字段”是绑定后的字段槽位，不是字段在源表中的固定顺序。文本“#2, #7”及两次单选有明确顺序时沿用该顺序；宿主多选只返回集合时，按原始物理编号升序绑定槽位，不猜点击顺序，再显示解析后的轴。用户可覆盖默认方向。类型未确定时不提前承诺坐标布局。

明确一个横轴字段即可，另一字段自动作为纵轴。用户同时指定 X/Y 时先校验恰好为所选两字段且各用一次。界面默认高亮不是用户指定；仅两字段和类型已经确定后，系统才按上述规则计算默认方向。

交互式选择复用既有一次组合确认，摘要示例：

> 分析字段：#5 温度、#8 PM2.5；有效数据：33,746 行。
> 绘图：横轴为温度，纵轴为 PM2.5。
> 分析方法：按当前方法计划列明实际候选。
> 此处只指定图的展示方向，不表示因果关系。
> 操作：开始分析 / 交换横纵轴 / 修改字段。

“交换横纵轴”更新摘要，再等待针对新摘要的确认；不重新选择文件、字段或类型。“修改字段”沿用局部纠错。用户已完整给出文件、sheet、字段及必要语义时，仍展示摘要后直接运行，不因未指定轴增加一次确认。用户已明确 X/Y 时采用其指定。

## 核心数据与接口契约

字段身份仍由既有两个槽位及物理编号绑定。绘图轴是独立的展示参数，不能反向重排分析输入。

| 对象或入口 | 新增契约 |
|---|---|
| `action.plot_x` / `state.plot_x` | `auto`、`col1` 或 `col2`，默认 `auto`；显式选中另一槽位等价于交换轴。只存横轴意图，纵轴自动取另一槽位 |
| `PlotAxis` | `slot`：col1/col2；`column_index`：源表 1-based 物理编号；`label`：完整显示名称；`feature`：null 或日历派生特征标识 |
| `PlotPlan` | `requested_x`；`kind`：scatter/box/heatmap/timeline；`x/y`：PlotAxis；`source`：explicit/type_default/slot_default。主图的 x/y 必须绑定两个不同槽位 |
| `summary.plot` / `result.plot` | 共用同一纯解析函数产生主图 PlotPlan；选择阶段只解析类型和布局，不调用统计计算。相同字段语义和 plot_x 请求必须得到相同轴映射与来源 |
| `analyze --plot-x` | 取值 auto/col1/col2，默认 auto；保持原有 col1/col2 参数含义。ready 的 `analysis_args` 原样传递 state.plot_x，含 auto，避免将系统默认误记成用户显式指定 |
| `figures[].axes` | 每图实际 `x/y` 的 PlotAxis；主图与 result.plot 对应，派生图记录自己的轴；图片、HTML、Markdown 使用同一份映射和完整字段名称 |

`plot_x` 和解析后的轴映射纳入摘要确认范围；轴变更使旧确认失效，变更请求不能顺带确认尚未展示的新摘要。切换文件/sheet 或替换任一字段时将旧轴指定恢复为 auto；同一次请求中的新轴指定对更新后的字段生效。仅修正类型或等级顺序时保留显式槽位意图并重新解析布局，撤销旧确认；修改方法保留轴，分页/搜索不改变轴。

无效绘图参数在入口报错并保留原有合法字段，不静默改轴，也不给出可执行分析参数。`--no-chart` 仍记录计划、不生成图片，不为此额外询问轴。新默认绘图方向以本规格为准，不提供旧方向或旧状态的兼容层；统计输入契约不变。

## 绘图与报告保证

- 交换轴只改展示模型中的轴引用、绘图数组、标签、日期格式与布局，不交换传入统计引擎的列。原始 methods/tests/effects/conclusions/comparisons/multiplicity/cleaning 等统计字段保持不变；带编码方向的效应说明继续对应原始字段身份。
- 散点图交换 x/y 数组及对应日期格式。现有趋势线按新坐标重新计算绘制，不能仅交换标签或镜像旧线；趋势线仍为辅助观察，不新增回归推断或因果结论。
- 箱线图支持横向和纵向布局，分组、数值、分位数与有序等级顺序保持一致；时间与类别图支持时间在 X 或 Y，日期刻度跟随时间轴，类别轴保留原有顺序与含义。
- 热图按指定方向决定行列，必要时仅转置绘图副本；统计列联表和 CSV 不转置。类别截断及标签映射随展示矩阵一致更新，不改变完整样本计算。
- 日历派生图使用自己的实际轴，例如 X 为状态、Y 为月份；不机械套用主图“时间/状态”两原始列。主图交换不改变派生图定义，其各自轴在图注中明确。
- 图上和图注显示完整的“横轴：…；纵轴：…”字段身份，热图同时注明颜色表示记录数。HTML/Markdown 的说明一致；更长名称可换行，不依赖截断后的图内短标签识别。术语遵循首次中英文、后续中文。

## 主链路

1. 交互选择：文件/sheet → 两字段 → 必要语义 → 解析默认轴 → 摘要显示轴与方法 → 开始分析，或交换后重看摘要并确认 → 传递同一绘图请求并共用规则解析 → 完整发布报告。
2. 完整输入：用户给出完整选择及可选 X/Y → 校验字段与语义 → 按显式指定或默认规则解析轴 → 显示同一摘要后直接分析 → 各图记录真实轴，结果与原统计契约一致。

## Feature Task

- [x] T1 — 交付能默认解析、显式指定和交换横纵轴的选择契约，使用户在既有确认流程内明确展示方向，并保证最终调用与摘要一致。
- [x] T2 — 交付现有各类主图的正确坐标方向与标签，使交换轴后的数据、日期、等级和辅助趋势线对应，且统计输入与结果保持不变。
- [x] T3 — 交付可追溯轴映射的统一报告与技能交付指引，通过选择到实际产物的回归证明用户指定、摘要、图形和机器结果一致。

以下断言已转为单元测试与冻结对话样例并执行；分阶段与完整 Feature 的结果见完成证据。

| 用例 | 必须落到测试中的断言 |
|---|---|
| A1 默认与类型 | 双数值、单时间/数值、双时间、分类/数值、等级/数值、时间/类别、时间/等级、双分类和双等级均符合默认表；语义改变后重新解析，摘要不承诺旧布局 |
| A2 显式与交互 | 同批字段可指定任一槽位为 X；无序多选按稳定编号绑定；默认高亮不成为显式指定；交换仅改轴、不清除合法选择；旧确认失效，方法修改及分页按契约保留轴 |
| A3 直达与调用 | 完整输入仍无需新增确认；默认和显式方向都传入准确 argv；选择阶段统计调用次数为零；文件/sheet/字段替换重置旧轴，名称重复时绑定物理编号 |
| A4 图形正确 | 每类主图双向布局与计划一致，含非方形热图、长字段名、等级顺序及时间在 Y 轴；绘图调用截获数据/标签/格式对应，散点趋势线重新绘制；派生日历图轴独立且真实 |
| A5 统计与交付 | 固定数据、方法、种子和次数，交换轴前后原始统计字段完全一致；HTML/Markdown/JSON 轴说明一致，复用完整发布与故障隔离测试，不泄漏临时路径；--no-chart 保留计划而无图片 |
