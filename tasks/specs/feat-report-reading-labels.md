# Feature：报告坐标说明与页尾精简

- 标识：report-reading-labels
- 状态：进行中且检查点通过；实现及自动化验收通过，真实浏览器检查未完成。
- 适用对象：阅读和分享 HTML/Markdown 关系分析报告的用户。

## Non-Goals

不更改选择交互、统计结果、图内坐标与复现数据，不新增依赖或同步外部安装。

## 业务意图

减少重复的坐标提示，让读者直接看结论；在各图图注保留真实横纵轴，并用“数据科学:相关性分析 / {version}”作为页尾展示名称。

## 核心契约

- 共享 ReportModel.sections 的 summary/figures 不再包含单独的轴说明段落。
- 每图 caption/axes/alt 与 plot/reproduction 保留；缺图时保留图注与具体原因。
- HTML 与 Markdown 同步改页尾，内部模板 ID 保持不变，版本为 1.4.1。

## 主链路

分析结果 → 共享内容模型 → HTML/Markdown；坐标仅在图注展示，页尾品牌一致。

## Feature Task

- [ ] T1 — 交付坐标提示精简且页尾一致的双格式报告，使读者直接理解结论并从图注核对绘图方向。

## 验收锚点

报告回归与绘图发布集成测试；五类实际报告的正文、图注、页尾与复现信息核验；真实浏览器宽/窄屏检查。命令、范围与停止条件冻结在工作台。

## 完成证据

- S26 已实现坐标仅在图注说明，页尾统一显示“数据科学:相关性分析 / 1.4.1”；模型的真实坐标与复现数据保留。
- 40 项自动化测试通过，无失败/错误/跳过；五类实际生成的 HTML/Markdown 共 10 份报告通过正文、图注、页尾、图像、缺图与发布/复现核验。见 [验收记录](../../evidence/dasci-relationship/report-reading-labels/acceptance.json)。
