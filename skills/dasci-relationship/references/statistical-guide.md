# 类型、方法与统计限制

需要确认字段类型、核对候选方法、解释方法差异或小样本/稀疏表结果时查阅；实际方法状态与数值以本次脚本结果为准。调用参数与机器结果见 [analysis-contract.md](analysis-contract.md)。

## 方法选择矩阵

脚本按有效业务类型形成下列默认候选，逐项核对适用条件；交换列顺序保持方法集合。

| 列 1 类型 | 列 2 类型 | 方法 | 说明 |
|---|---|---|---|
| 数值 | 数值 | Pearson、Spearman、Kendall τ-b | 线性和单调关联；只有 Pearson 提供适用的 Fisher-z 单项区间 |
| 数值 | 二分类 | 点二列、Welch t、Mann-Whitney U | r_pb、Cohen's d、秩二列相关和分组摘要，方向依据 0/1 映射 |
| 数值 | 多分类 | ANOVA、Welch ANOVA、Kruskal-Wallis | 均值与秩分布问题；分别保留 η²/ω²、组均值摘要、ε² |
| 数值 | 有序 | Spearman、Kendall τ-b | 使用用户确认的顺序，不假定等距 |
| 数值 | 日期 | Pearson、Spearman、Kendall τ-b | 日期转 epoch 天，记录时区处理和独立观测限制 |
| 二分类 | 二分类 | 卡方、双侧 Fisher、G 检验 | φ、V、优势比；卡方/G 的稀疏校准各自使用对应统计量 |
| 二分类 | 多分类 | 卡方、G 检验 | V、完整频数、互信息 I（nat，仅描述） |
| 二分类 | 有序 | U、Spearman、Kendall τ-b | 等级频数与秩方向；方法高度相关，不能计票 |
| 二分类 | 日期 | 时间戳 U、日历筛选 | 分开描述时间位置和日历模式；无日历特征时保留原因 |
| 多分类 | 多分类 | 卡方、G 检验 | 名义分类独立性与完整频数 |
| 多分类 | 有序 | Kruskal-Wallis、卡方 | 前者利用顺序，后者忽略顺序比较类别分布 |
| 多分类 | 日期 | 时间戳 Kruskal-Wallis、日历筛选 | 时间位置和日历模式分别记录 |
| 有序 | 有序 | Spearman、Kendall τ-b | 两列完整顺序和并列秩校正 |
| 有序 | 日期 | Spearman、Kendall τ-b | 等级随时间的单调关联 |
| 日期 | 日期 | Pearson、Spearman、Kendall τ-b | 共同时间趋势不代表因果 |
| 文本/高基数 | 任意 | 不直接分析 | 报错并建议先分组/编码；不要强行做极稀疏的列联表 |
| 标识符 | 任意 | 不分析 | ID/编号每行唯一，相关性没有实际意义 |
| 空列/常量 | 任意 | 不分析 | 没有变异，无法分析关系 |

### 类型是怎么推断的

脚本会给出 `kind` 和中文 `type`：

- `numeric` 数值：数值 dtype，或 ≥95% 可解析为数值的字符串（支持千分位、货币符号、百分号、括号负数、万/亿）。
- 数字低基数（包括纯 0/1）仍按 numeric 推断，只给类型建议；业务类别须确认后覆盖。
- `boolean` 布尔/二分类：bool dtype，或 true/false、yes/no、是/否 等两值文本。
- `datetime` 日期时间：datetime dtype，或 ≥95% 可解析的日期字符串（支持 `2024-01-02`、`2024/1/2`、`2024年1月2日` 等）。
- `categorical` 分类：非数值、取值数有限的列。
- `ordinal` 有序分类：仅由用户指定类型并提供完整顺序；不按字母/文本排序猜测，不假定等级等距。
- `text` 文本/高基数：不同取值 >50 且唯一率 >50%；这种列不能直接当分类变量。
- `id` 标识符：列名像 ID/编号且几乎每行唯一，或值呈前导零/长十六进制。
- `empty` 空列：整列为空。

类型是**推断**，用户确认的业务定义通过 `--col1-type/--col2-type` 生效，`kind` 与 `effective_kind` 反映实际准备类型，`inferred_kind` 保留原推断，`type_source` 为 `inferred` 或 `user`。有序水平按原标签文本匹配，数字 JSON 水平可匹配同文本文件值；例如 `[1,2,3]` 可匹配文件中的 `1/2/3`，`01` 与 `1` 保持不同。

CSV 和 Excel 使用同一缺失标记策略；`无/否/0/false` 是合法观测，不会被全局删除。数值/日期转换失败及非有限数值单独计数，配对过滤后再次检查变异；整列有多个值并不保证有效配对仍有多个值。

## 依赖与限制

- 运行时不依赖 SciPy；t/F/卡方分布、双侧 Fisher、Kendall τ-b、Welch ANOVA 和 G 检验是内置实现。
- Spearman/Kendall N<30、U 任一组<10、KW 任一组<5 时用对应秩统计量置换；其余样本使用标明的渐近近似。相关/U 为双侧，KW/χ²/G 为上尾，Fisher 为双侧。置换依赖独立观测在原假设下可交换；相关置换是固定边际重新配对的秩关联检验，不能解释为检出任意依赖。
- 稀疏表的卡方/G 使用各自统计量置换，日历叶子遵循相同规则；`--permutations 0` 时小样本秩检验和稀疏表 χ²/G 均为 descriptive_only、p=null，适用的 Fisher 仍可执行。Monte Carlo p=(极端次数+1)/(B+1)，不会为0。每项记录请求/实际 B、seed、alternative、permutation_extreme、p_resolution=1/(B+1)、mc_standard_error≈sqrt(p*(1-p)/B)；后者只是估计标准误，p=1 时为0不表示无模拟误差。默认 B=2000 的分辨率约0.0005；不应把很多小数位当作等量精度。
- Pearson N≤3 或完全相关不提供 Fisher-z 区间，Spearman/Kendall 不借用该区间；未定义的效应（如零分母 d、无限优势比）使用 null 并说明原因。
- 皮尔逊相关只衡量线性关系；非线性关系请结合散点图和 Spearman。
- 有序字段默认用秩方法；有序×多分类另列卡方，明确它忽略顺序。二分类和等级编码方向须随效应呈现。
- 日历筛选的每个特征是独立叶子记录，容器没有整体 p；各叶子的原始 p 与其他有效检验直接进入同一 Holm family，不先 Bonferroni 再次校正；不将最低日历 p 作为整体独立性结论。
- 缺失与转换失败按完整配对处理。`total_rows` 是去掉全空行后的行数，`missing_pairs=total_rows-n` 包括转换失败配对与其余缺失配对；精确分解见 `cleaning`。不要把缺失说成随机缺失。
- 默认**第一行是表头**；多行表头、前置说明行、合并单元格请先清理成规整的二维表，否则列名和类型会不对。
- Excel 中的公式列如果没有缓存计算结果，读取时可能为空；请先在 Excel/LibreOffice 中重算并保存，再重新分析。
- 所有结果都是观察性关联，不能直接用于因果结论；如有混杂变量，建议做分层分析或回归调整。
